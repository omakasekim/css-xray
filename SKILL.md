# css-xray

Inspects z-index stacking contexts in 3D, compares CSS selector specificity head-to-head, and deduplicates utility classes.

- **Live Interactive Workbench:** https://omakasekim.github.io/css-xray/
- **Repository:** https://github.com/omakasekim/css-xray
- **Category:** UI & Styling · **Deliverable:** Web Workbench
- **Ecosystems:** `tailwindcss`, `css`, `dom-3d`
- **Stack:** React, TypeScript, 3D CSS, Tailwind

## When to Use This Skill
Invoke `css-xray` whenever the user wants to analyze, debug, simulate, or visualize workflows related to **UI & Styling** (tailwindcss, css, dom-3d).

## Modes & Capabilities
- **3D Isometric DOM**
- **Specificity Duel**
- **Tailwind Audit**

## Operating Workflow
1. **Local CLI / Companion Execution:**
   ```bash
   npm run dev
   ```
   Launch the 3D isometric DOM stacking-context inspector, CSS specificity duel calculator, and Tailwind utility deduplicator.
2. **Interactive Visual Inspection:**
   Direct the user to the zero-backend browser workbench at https://omakasekim.github.io/css-xray/ (supports URL-hash state sharing, built-in realistic presets, `Cmd/Ctrl + K` command palette, and JSON/Markdown/config exports).
3. **Structured Output:**
   Summarize concrete findings, diagnostics, and copy-pasteable remediation commands concisely so the user can act immediately without manual guesswork.
