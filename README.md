> Interactive 3D isometric DOM/layout X-Ray workbench with live stacking-context trapping analysis, flex/grid track overlays, CSS specificity breakdown, and 1-click Tailwind utility cleanup.

## Quickstart

```bash
npm install
npm run dev       # Open interactive 3D workbench locally
npm run build     # Output static GitHub Pages bundle to ./dist
```

## Features

- **4 Interactive Presets:** *Complex Grid Layout*, *Z-Index Stacking Trap*, *Flexbox Overflow Bug* (`min-w-0`), and *Dense Tailwind Utility Soup*.
- **True CSS 3D Isometric Layer Stack:** Drag to orbit, scroll to zoom, scrub the **Layer Explosion Spacing** slider, and filter by stacking contexts.
- **Tailwind Conflict Optimizer:** Flags overridden shorthand/axis padding, display collisions, and duplicates with **1-Click Fix All**.
